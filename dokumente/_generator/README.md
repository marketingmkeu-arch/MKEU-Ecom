# Generator für den Mietvertrag

Erzeugt `../Mietvertrag_moeblierte_Wohnung.docx` neu.

```bash
npm install docx
node build-mietvertrag.js ../Mietvertrag_moeblierte_Wohnung.docx
```

Änderungen am Vertragstext bitte hier vornehmen und die .docx neu erzeugen,
damit Quelle und Dokument nicht auseinanderlaufen.
